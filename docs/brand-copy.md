# Brand copy · 三语文案对照

> 用法：页面只用简中版；繁中 / EN 用于 GitHub、作品集、个人陈述、CV 与演示稿。
> 抬头结构固定为「产品名（标题）+ 一句话简介（小字）」，不要再加第三行 slogan。

## 00 · 产品名

**Prompt Assistant** — 简中 / 繁中 / EN 三语相同，**不翻译、不改写成中文、不加冠词**。

| | 简中 | 繁中 | EN |
|---|---|---|---|
| 产品名 | Prompt Assistant | Prompt Assistant | Prompt Assistant |
| 短句（tagline） | 画面之前 | 畫面之前 | Before the image |

短句用于浏览器标题、侧栏小字、图标旁注、repo 短描述。不解释功能，只留一个时间点：生成结果出现之前。

> **命名沿革**：项目目录、桌面 `Prompt Studio.command`、图标文件 `Prompt Studio.icns` 仍沿用旧名 `Prompt Studio`，这是路径与 Finder 元数据依赖，**不是笔误，也不要批量「修正」**。对外产品名以 `Prompt Assistant` 为准。

## 01 · 页面抬头

| 位置 | 简中 | 繁中 | EN |
|---|---|---|---|
| 标题（H1，产品名） | Prompt Assistant | Prompt Assistant | Prompt Assistant |
| 小字简介 | 写下所想，其余由它铺陈 | 寫下所想，其餘由它鋪陳 | Write what you mean — the rest is composed. |

用户定稿句为「写下所想，其余由它铺陈」，简中 / 繁中**不加句末标点**（中文设计里更干净）；EN 按英文习惯保留句号与破折号。

设计说明：这一句把「用户只负责表达、其余交给系统」的分工说清，同时含蓄带出核心产品决策（戏份由模型推断，不向用户提问），不出现「自动判断」「一键」「帮你」这类功能说明书或讨好口吻。

## 04 · 用词禁忌

不要回退到以下表达，它们正是「直白 / low / 尬」的来源：

- 拟人化：`模型听得懂的话`、`让想法被听懂`、`AI 帮你`
- 讨好口吻：`…就好`、`轻松`、`一键`、`只需`
- 功能说明书进抬头：`自动判断这是什么戏份`、`重新组织镜头光线与细节`
- 空泛高级感：`赋能`、`重新定义`、`释放创意`、`让灵感发生`
- 被弃用的文艺标题：`把未成形的，写成可生成的` / `Give the unformed a form.`（用户最终选择直接用产品名当标题）
- 把产品名译回中文，或写成 `Prompt 助手` / `提示词助理`

繁中不是简中的机械转换：用「鏡頭／分類／鋪陳／本機／使用者」，避免「自動判斷」「用戶」等直译词。EN 不做逐字翻译，按英文产品文案的节奏重写。
